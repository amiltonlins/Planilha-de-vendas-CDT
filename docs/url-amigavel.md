# URL amigável do Painel Comercial

O aplicativo está hospedado no Streamlit Community Cloud. A URL pública não é definida pelo código Python do painel.

## Opção suportada diretamente pelo Streamlit

No painel do Streamlit Community Cloud, abra **Manage app > Settings > General > App URL** e escolha um subdomínio curto disponível, por exemplo:

`painel-afogados.streamlit.app`

O nome final depende de disponibilidade no Streamlit.

## Domínio próprio

Um endereço como `painel.seudominio.com.br` depende de configuração externa de domínio/DNS e de uma camada de redirecionamento ou proxy compatível com a hospedagem escolhida. Não altere autenticação, banco ou código do painel para simular esse domínio.
